# Cpp-Fundamentals

## Description
This repository contains my practice projects and exercises while learning the fundamentals of C++. It covers the basics of programming including: 

- `if` statements and conditional logic
- Loops (`for`, `while`, `do-while`)
- Arrays and basic array operations
- Functions and simple function usage
- Beginner-level programming concepts and problem-solving

## Purpose
The main goal of this repository is to apply what I’ve learned in a practical way, build confidence in C++ basics, and create a foundation for more advanced topics in the future.

## Projects/Exercises Examples
- Basic calculator using `if` statements
- Array operations: sum, max, min, copy, count positive/negative numbers
- Simple number theory exercises: prime numbers, perfect numbers, palindrome checks

## Audience
This repository is aimed at beginners in C++, or anyone looking for clear, simple examples of core C++ concepts.

## Usage
Clone the repository and try running the exercises in **Visual Studio** or any C++ IDE to understand basic programming logic. Modify and experiment to strengthen your understanding.
